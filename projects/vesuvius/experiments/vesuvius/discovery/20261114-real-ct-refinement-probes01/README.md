# R184 PHerc0343の実CTで評価窓を比較

2026-11-14 JST。固定4点×3条件で、中心化による法線方向の補正量の変化は **−7.329〜+1.082 voxel**。最大差の節点 (306,39) では、角基準と中心化で不透明度の寄与が別の深さ帯に集中した。4点の結果から対象の物理紙面は決められない。未知面への全面適用は見送り、元面・角基準・中心化が既知字画に与える影響を、既知対照の小領域で比較する次案を残す。

## 固定位置と採取

[一次] 凍結R183の `vc_objrefine`、R160の `vc_core` / `vc_reader_native` の実リンク先とSHAを照合。r3角基準（center_window省略）、r3中心化（true）、r0を同じ4点OBJに各1回。L0、reader_scale=0.5、深さ−2…16 voxelを1刻み、border_off=0、閾値118/255と165/255、cache_mb=32。C/ext4の新出力先で処理し、製品OBJをそのまま保存した。[製品・共有体SHAとhelper構築](build-plan.json) · [実入力と設定SHA](product-input.json) · [製品OBJと各工程原票](product/)

[一次] 各補間点のfloorと+1の8角を先に包絡し、製品3条件の合併は7キー、2方向断面も含むと8キー。断面だけに必要なのは `0/80/30/33`。元CT v2 L0、無圧縮uint8、128³チャンク、補間支持内の全キー実在。必要な8キー計16 MiBはR173/R180の保存本文を長さとSHAで確認し、新しいローカルZarrから参照した。欠損・通信は0。研究中の連絡で断面専用キーを一度誤記したが、事前の支持原票の集合は正しい。[支持と再利用元](support-plan.json)

[一次] 断面は各Pを通るBx–NとBy–Nの2面。接線±14 voxelを0.5刻み、法線−2…16を1刻み、表示は全図共通0–255 DN。白点は元P、色付きの候補はそれぞれの補正量に対応するP+dN。角基準の色付き点も移動先の法線上に描いた。角基準の強度評価窓中心は接線側のP+6Bx+6Byで、断面の白線上の生強度はr0と同じ。下段に3条件のぼかし後DNと不透明度寄与を示す。[4点断面と深さプロファイル](sections.png) · [節点別原寸と注記なし断面](figures/)

- (88,69) と (299,41) は、三候補ともそれぞれ同じ幅広い明帯の範囲に見える。前者の角基準では走査先頭のd=−2にも0.185の寄与があり、主なd=4…6の帯に加わって候補を手前へ引く。後者は主寄与がd=5…8に集中する。
- (306,39) の断面にはd=0付近とd=8以深に明帯が見える。角基準の最大寄与はd=10、中心化はd=0、r0はd=−1。中心化は全積算不透明度0.224で、r0の0.957より低い。中心化しても近い側の物理紙面を同定した根拠は増えていない。
- (324,39) は複数候補が幅広い明部内にあり、窓配置で寄与が前後する。r0の最大ぼかしDNはd=7だが、先行するd=3の寄与が最大で、加重変位はd=+3.174。これは強度の最大深さと前から積算した結果がずれる例。

[推論] 角基準→中心化は同じr=3の採取位置だけの変更。r0との比較には接線方向のGaussian平均の有無も含まれる。各窓の積算では前の層の寄与だけ後続の透過率が減り、複数深さの加重平均が返る。今回の図は補正候補を示すが、明帯の帰属と領域全体の連続性は判定できない。R173/R175の既知字画再現は形状対照として参照できる。主担当は、元面・角基準・中心化をR173/R175の既知字画を含む小領域で比較する次案を採用した。その比較で見るのは、既知字画の位置と形が保持されるか。未知面の同一紙面を選ぶ判断には、引き続き独立に追える目印が複数地点で必要。

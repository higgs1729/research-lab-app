## 目視判定

- 3144。右下でCTの大きな裂け・変形に沿う形が両予測にも見える。左側の縁付近には広い強応答、内部にはぼやけた斑点と小さな不定形の強応答。繊維方向に沿う筋や欠けから区別して、隣り合う独立した字画を一つの行として追える位置は特定できなかった。黒い領域とメタデータの欠損4 CTチャンクの関係、欠損のXY位置と予測への影響は未確定。
- 4203。CTで横切る層状の歪みと縦横の繊維が目立つ。予測では輪郭寄りの帯や、孤立した広い強応答、細かい不定形の斑点を確認。複数の字画に分かれて一定の高さ・間隔で続く列は指せなかった。公開レンダーメタデータの欠損チャンク数は0。

両面とも、この固定6画像を根拠に元CT追試へ進める候補は選ばなかった。採択候補座標・転写は空。インクの有無、物理紙面の対応、別深さやモデルでの結果は未判定。アトラス全体のカードは公表学習リストに対象巻がないと説明する。両面の実際のメタデータでは7モデルすべて exposure.status=unknown、source=null。対象メッシュと学習、先行判読、w083_mainの物理重複は確認できていない。予測とCT画像は公開アトラス作者の成果で、今回の追加は固定取得・表示・候補判定。

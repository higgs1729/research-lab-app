# R185 PHerc0343の既知字画部分で面補正を比較

2026-11-14 JST。**この固定領域・設定では、角基準と中心化の両補正で既知字画部分の再現性が下がった。元面を対照として維持し、両補正の未知側への適用は見送る。** 元面は既存R175と同じ位置に曲線や囲まれた暗部を再現した。両補正後では対応形が弱く、同じ位置に追いにくい。

## 固定条件と実装

- [一次] PHerc0343のR173元mesh、atlas XYWH [1344,1024,384,384]、主比較は [1408,1088,256,256]。受賞者の公開box9の一部とbox10右端に重なる。全一文字や文字列を評価できる範囲は含意しない。[R179の位置照合](../20261114-known-neighbour-selection01/lead-known-check.json)
- [一次] 既定bicubicの補正に渡す小tifxyzを元mesh列72…99・行54…82から作成。元の全2,436 float32 XYZ値とscaleを保持。描画に寄与する範囲を含む552節点で、局所と全面のbicubic法線の各成分がビット一致。全756有効補正節点の角基準・中心化の8隅支持を、丸め余裕0.002 voxel込みで確定してからR183凍結CLIを各1回実行した。r3、reader_scale=.5、L0、−2…16 voxel/step1、border_off=0、low118/255・high165/255、cache_mb=32。実際に移動した節点は角基準695、中心化688。[局所法線・支持](local-support.json) · [角基準設定](corner.json) · [中心化設定](centered.json)
- [一次] 得られたfloat32 XYZを、元と同じ128×336寸法の描画用コピーへ貼り戻した。補正対象外42,196頂点のXYZは全ビット一致し、局所812頂点も各tifxyzからビット一致で移した。固定9点を主担当が別算術で照合し、補正量の誤差は角基準最大0.002455、中心化0.000623 voxel。全面の補正は実行せず、元面と描画用コピー3面の全く同じ384²だけを採取した。OBJ経由の丸めは入らない。[保存面](surfaces/) · [主担当の面照合](lead-mesh-check.json)
- [一次] 既存observerで各面36区画、計108区画のP/Nを採取。元面のR173同位置との差は最大成分でP 0.001953 voxel、N 4.53×10⁻⁶。元と同じglobal canvasの画素格子を照合した。変位後の面には実際の線形法線を使い、補正面と元面の法線差も保存した。全3面147,456画素ずつ有効。補正前の支持は45キー、3面の描画支持は37キー。補正・描画で各1キーを公式L0から取得し、長さとETag/MD5、SHA-256を照合した。合計4,194,304 B、通信7.763秒。残りはR173/R180保存本文。支持内の欠損なし。[補正支持](ct-refine-support-final.json) · [描画幾何](render-support.json) · [描画支持](ct-render-support-final.json) · [取得1](ct-refine-result.json) · [取得2](ct-render-result.json)

## CTと推論

[一次] R173と同じrenderer ELF/共有ライブラリ、scale=.9、linear、step1.111、nonflip、33層で元面・角基準・中心化を各1回描画した。各面の全4,866,048値でTIFF/Zarr一致。元面はR175の保存CTに対して4,861,738値が一致し、4,310値が±1 DN、MAE 0.000886 DN。同一画素格子における小さな数値差のため、票の条件通り元面の予測も今回入力で再計算した。CT中央の実画像では、補正後に繊維や暗部の位置・見え方が変わる。元面に対するモデル入力17層のCT MAEは角基準32.744、中心化32.636 DN。[CT照合](ct-comparison.json) · [主担当の直接補間](lead-render-check.json)

[一次] 3面×既存seed42・dense-nativeの計6回。既存CPU経路、層24→8の17枚、128²パッチ、stride64、25パッチ、robust-MAD、Hann、batch1、workers0。全6実行の公式ソース・重みSHA、モデル別のCLI引数はR175と一致（入出力パスのみ相違）。各モデルで重み和が3面で全値一致。元面予測のR175との差は主比較で最大1 DN、MAEはseed42 0.142、dense 0.075 DN。[実入力と出力](inference/) · [実行原票](model-run/)

[一次・目視] 全表示を0–255、1画素1 pxで比較。dense-nativeの元面と公開図は右上寄りの囲まれた暗部と、その左下から回る明るい形が同じ位置に見える。角基準では明部がいくつかの丸い塊へ分かれ、中心化でも右側の暗部を囲む同じ輪郭を追いにくい。seed42の元面と公開図は中央右の明部と左上側の曲線状の並びが概ね対応する。角基準では左上の明部の連続が弱まり、中心化では左右の広い強応答がつながって元の配置が崩れる。両補正で残る明部はあるが、固定範囲では既知形状の保持を支持しない。[固定主比較図](comparison-interior-256.png) · [全384²図](comparison-384.png) · [数値原票](comparison.json)

[推論] この固定条件での面移動とそれに伴う法線変化を含めた結果。どちらの寄与が主因かは分離していない。公開との画素一致は再現性の指標。対象紙面の正しい位置、読取精度、別の深さ窓での結果は未測定。既知形状の保持という条件を通過しなかったため、今回の両補正を未知側へ転用しない。人工対照R183で成立した中心化の幾何的性質は、そのまま実CTでの字画保持を保証しない。

## 共通断面の観察

三高さz11760、11952、12240、三列x256、1024、1792。w053基準の共通radial rayから各地点のXY/radial-Z断面を重ねて読んだ。18枚のマークなし画像は、L0から元のDNを三線形補間してuint8に四捨五入したもの。個別5倍表示のマークは三面の同一radial位置を示す。親の別計算で全57,156画像値が元CTから一致した。 [断面一覧](sections-result.json) · [元CTの独立照合](lead-ct-check.json)

中心列z11952ではw052が暗帯に重なり、w053とw054の位置では境界近くの単一ラミナを特定できなかった。z12240でw052に局所の細い明帯を追えたが、w053は広い暗部、w054はその縁付近。z11760では粒状域や曲がる境界の中で三面とも帰属が曖昧だった。暗部はラミナ対応が弱い箇所を示す所見で、組成や層間を一意に確定できない。中心3地点の必要条件を全ての面が欠き、独立性による代表選定は適用しなかった。 [中心z11760](sections/z11760-x1024-marked.png) · [中心z11952](sections/z11952-x1024-marked.png) · [中心z12240](sections/z12240-x1024-marked.png)

## 実行量

公式L0の予定29キーのみをHEAD/GET、200と同ETagを照合し、60,817,408 B（58 MiB）を79.182秒で受信。再試行なし。座標確定は1.40秒、製品9子処理は計6.86秒、断面採取約2.45秒。最大RSS133,844,992 B、主要工程CPU1/commitまたはAS4 GiB。製品はネットワーク分離、D読取。C作業約58.4 MiB、空き21.8 GiB以上を確認。訓練、重み取得、モデル推論、GPU、課金、外部公開は0。 [HTTPと実長](ct-acquisition.json) · [転送の実行](ct-process.json) · [断面実行](section-render-process.json)

座標の初回出力はNumPyのboolのJSON変換で停止し、実行記録と書きかけを保存。ネイティブboolに変換して同じ条件で正常出力した。幾何のみの製品起動初回は借用アダプターのモジュールimportで停止し、ローカルヘルパーを参照するよう修正した。入力・条件とも再選定していない。 [初回座標記録](coordinate-process.json) · [出力成功記録](coordinate-process02.json) · [初回製品起動](observer-initial-failure.json)

## 表示とatlasの境界

原JPEGは両方1773×786 RGB。公開原寸で目視し、右パネル周辺のJPEG画素を切り出したPNGでも各画素が元JPEGの復号値と一致することを確認した。階調、スケール、強調は変更していない。追試では右パネル中央から左下の斜めの強反応と右上の枝分かれに、暗い割れや穴に接する部分がある。親カードには離れた斑点と下寄りの輪状反応があり、同じ幅の独立画が連なる行として追えなかった。主担当も両原画を別に目視し、文字追試ROIを採らなかった。既知PHerc0343のR168では逆順atlasに離れた画と行のまとまりが見えたが、R168は生の8bitグレーatlas表示、今回は加工済みカードであるため検出感度の比較には使わない。[親カード原寸切出し](2765_2952_4205-card-native.png) · [追試カード原寸切出し](2601_2784_3851-card-native.png) · [主担当の独立目視](lead-review.json) · [既知表示対照](../20261114-atlas-known-control01/README.md)

固定 `draw` の黄色は選んだ面の正規化済み2予測の平均を再正規化し、`(x-.5)/.4` でクリップしgoodでマスクした、CTとの合成表示。固定コードはパネルをbilinearで半分に縮小する。黄色をそのまま上位3%の交差マスクや暗部率へ置き換えられない。弱い反応の消失、明部の癒着、JPEG圧縮の影響があり得る。さらに固定コードのカード幅式は `2×panel_width+420` で偶数だが、保存JPEG幅は1773。生成後の変換や同版コードからの正確な出力対応が確認できず、JPEG上のXYをCT・生mapのXYへ換算しない。[カードコード](report_card.py) · [原寸確認](inspection.json)

## 一つの条件付き識別実験

公開カード上に文字ROIを採らない。もし同じ描画のCT中央層、seed42・dnativeの両順の未合成マップ、評価マスクとnative XYの原点が確認できれば、同じ画素の上位3%交差と暗部の一致を直接検査できる。固定木からその組は特定できない。一方、同じ公開面の幾何だけを固定し、カード座標に依存しない独立のCT対照は小さく計画できる。次はこの一案を選ぶ。

1. 固定 `results/meshes/PHerc0846A_2601_2784_3851` の3 TIFFだけを対象にする。固定木で各56,329 B、計168,987 B、blob IDを記録済み。メタは取得済み。公式9.362 µm masked volume `20250728152254-9.362um-1.2m-113keV-masked.zarr` のL0メタデータを先に照合し、3 TIFFはHEAD/サイズとGit blobを検査してから使う。座標はL0 XYZ。公開seed `(2601,2784,3851)` へのユークリッド距離が最小の有効TIFXYZ頂点を採り、同距離は行・列の昇順。その頂点のrenderer native canvasへの投影に最も近い画素を中心に128²を凍結する。頂点距離と投影誤差を保存。幾何が有効でseedの対応が取れない場合、または128²をキャンバス内に置けない場合は別地点へ動かさず停止する。これは公開カードの強反応部を再現する座標とは扱わない。
2. R165と同じR103観測版の64²四区画で基点・法線を取得する。L0、scale 1、上流描画実装に合わせlinear、非反転法線、33層 `d=-16…+16`、刻み1 voxel。元CT本文より先に有効域・隣接XYZ・全8隅＋0.001 voxel余裕を列挙し、候補キーをHEAD。TIFXYZ ≤1 MiB、CT ≤16キーかつ≤32 MiB、全本文≤34 MiB。CTが128³ raw uint8なら1キー2 MiBという見積もりで、実形式と必要量はメタデータ・幾何・HEADまで未確定。作業128 MiB、C:空き10 GiB、1CPU・AS4 GiB、取得/幾何/製品1回/集計各120秒、追加クラウド0円。欠損・ETag変化・範囲外・上限超過で停止。
3. 元CTの固定中央2断面（局所X/Y各64）と、同じ面の離れた平行断面（局所X/Y各32/96）を原階調で比較する。`d=0` をまたいで連続する単一ラミナを追えるか、暗帯が独立した空隙として表裏で続くか、幾何の飛びかを記録する。R129保存w035の中央断面は既知紙面の表示対照、同じROIの `|d|=8…16` は他の層や空隙の比較で無インクラベルとは扱わない。中央に一意な紙面がなく暗部との関係も追えなければ未判定で止める。単一紙面が一貫して追えれば、この新しいROIの後続判定に使える。結果を見て窓や面を変更しない。

この試験の陽性は新しい128²の紙面と割れの対応に限る。公開カードの黄色の原因は、位置登録された生mapが無い限り照合できない。次にモデルを使う判断がある場合は、紙面と割れの境界を先に固定して、既存seed42のCPUとw035工程対照を再利用する別の一件にできる。 [固定TIFXYZ一覧](fixed-tree.json) · [レンダー実装](render_patch.py) · [既存幾何・CT検査](../../../../research/165-pherc1218-sheet-diagnostic.md)

# PHerc0846Aの同じ近傍でHecate 9.6を比較

[研究199](../../../../research/199-pherc0846a-hecate-native-scale-pilot.md)。PHerc0846Aの固定seed `(2601,2784,3851)` の既存meshとL0元CTを使用した。9.6 µmの新canvas 2184²から `[896,896,384,384]` を切り出し、外周32pxを除いた `[928,928,320,320]` を主比較とした。旧9.362 µmキャンバスで、新出力の画素中心は各軸の919.030〜1311.767に対応する。旧R176の448²内に入るが、両者の画素格子と層間隔は異なる。 [座標原票](roi.json) · [旧R176の原寸図](../20261114-pherc0846a-aligned01/README.md)

既存observerの36タイル全147,456点で幾何が有効だった。33層の三線形補間支持に必要な32キーは既存44キーにすべてあり、新規取得0。既存製品rendererを一回実行し、保存ZarrとTIFF全33層の画素が一致した。保存metadataのZ/Y/X間隔は 9.600000549 / 9.599999914 / 9.599999914 µm。幾何描画288.275秒、製品描画9.419秒。親がmesh位置9点と元CT補間45点を別計算し、最大差は0.000452 voxelと0.494645 DNだった。 [支持](support-plan.json) · [既存CTの照合](ct-cache.json) · [描画原票](render/render-process.json) · [独立照合](lead-input-check.json)

固定公式Hecate 9.6と既存重みを用い、同じ中央16枚 `[8:24]` を両順で比較する条件とした。両方向の各121パッチ位置は、新全面2184²で主比較320²に届く全パッチと一致する。各パッチのraw値・正規化・支持を実行前に凍結した。開始時の空き物理RAMを8 GiB、進行中の下限を4 GiBとし、CPU1・Job commit4 GiB・FP32・batch1・64²・stride32、合計4500秒。最初の3パッチから残り239パッチの所要を見積もる。 [入力](input-contract.json) · [独立パッチ原票](lead-input-expected.json) · [実行前照合](preflight.json) · [中央CT原寸](ct-centre.png)

## 実行結果

空きRAM 11,276,640,256 Bで起動し、公式重みのstrict loadは12.081秒で完了した。順方向の先頭3パッチの境界間隔は36.112、19.363、11.704秒。2・3番目の遅い方×239の残り見積もり4,627.642秒が残り4,398.305秒を超え、4番目のforward前に停止した。順方向3/121、逆方向0/121、公式PNGは両方とも未生成。推論全体の実測は102.500秒、プロセスのpeak RSSは1,284,853,760 B、監視中の最小空きRAMは8,410,464,256 B。再実行、取得、GPU、追加費用は0。 [起動・停止](supervisor-result.json) · [推論原票](execution-result.json) · [所要判定](first-three.json) · [3パッチ](patches.jsonl)

この試行ではHecate像による字画・行の判定と、R176の二モデルとの目視比較は未実施。R176の結論は旧9.362 µmの固定近傍で二モデルとも候補を選べなかったことに限る。物理的な紙面の対応、Hecateの学習データでの同領域露出、インクの有無は未確認。

主担当は保存確率から3入力の位置・支持・SHAと12,288個の確率値、残時間判定、両方向PNGの不存在を別に確認した。中央CT単独の原寸では、担当と主担当が細い繊維状の構造と暗い溝状領域を確認した。 [独立検証](lead-verified.json) · [資源集計](resources.json)

## 次の一実験

**仮説**　公開箱の中央には、元CTの断面で連続する単一の紙面があり、平坦化面のゼロ法線位置から大きく外れていない。外れている場合、中心のズレ、隣接紙面の混入、紙面の飛びを分類する。先行の端で高いスコアに、形状と元CTから独立した説明がつくかを先に判定する。

1. 確率画像や新しいCTを開く前に、公開箱の中心256²を全体キャンバスの `x=[9162,9418), y=[2012,2268)`（8.64 µm/pxで名目約2.212 mm四方）へ固定する。中心は `(9290,2140)` の画素境界。表示する断面は `y=2076,2204` と `x=9226,9354`。端部の都合やスコアで動かさない。主担当が実行を決めた場合のみ、固定LFSのTIFXYZ三枚を逐次取得しSHAを照合する。
2. 既存R103の64²制約の観測rendererを16区画に使い、全体キャンバスの原点・画素中心・格子刻みを保つ。幾何のみの分岐が保存する基点 `P` と単位法線 `N` から、R140と同じL0/scale 1/bicubic、法線反転なし、`49×1 voxel` で `P+dN`、`d=-24…+24` の支持を列挙する。紙面側の名称をこの符号に割り当てない。四辺に必要な補間・法線支持を含め、有効XYが95%以上か、3Dで連続するか、8隅のCTキーと境界余裕を確認する。ジオメトリの欠損や不連続を出力に残す。必要CTは取得前に全件HEADし、公式Zarrの `/0/z/y/x` キー、長さ、ETagと総量を保存する。途中でキーを足さない。[R103観測版](../../r005/20261112-ct-render01/build02/vc_render_tifxyz.cpp)
3. 必要キーだけを取得した後、既存R123/R140製品をオフラインで同条件・同cropで1回描画する。`--pyramid false --zarr-compressor none`。元CTの8隅から代表点の値を照合し、固定階調の4断面に `d=0` と `d=±24` の位置を出す。既存R129/130の元CT由来w035の断面は位置・抽出の工程対照として、共通深さ範囲だけを同じ方法で見る。既知の訓練領域なので未学習性能対照としては使わない。対象内の `d=±16…24` は同じXYの対照断面として、遠い面や空隙にも同様の濃淡が出るかを見る。既知の無インクラベル扱いはしない。
4. 先行モデル図を隠した状態で、4断面に見える紙面を独立に追う。現状の幾何をそのまま使う目安は有効XY ≥95%、4断面中3以上で同じ紙面を両側へ追え、追えた断面の中央区間で代表的な紙面位置が `|d|≤2 voxel`、対象帯で同程度に追える別紙面への飛びがないこと。これは実験上の目安で普遍的な正解判定ではない。位置ずれ・飛び・多重面は計測値と位置を保存し、そのままの条件で未読探索へ進めない。連続した紙面の一貫した位置ずれなら、別の次実験で補正可能性を判断できる。紙面を追えない、または独立確認が一致しない場合はこの入力・深さで未判定として止める。CTに字形らしい濃淡が見えない場合も、インクなしという判定には使わない。

陽性は公開箱の独立した紙面診断まで。新文字候補を主張する段階では、候補箱、既知転写、訓練ラベル、公開された他面の実3D支持を照合し、画像と紙面の対応・独立読取を取る。学習と予測領域の非重複は必要だが、公開された未判読の候補・メッシュから離れることを一律条件にしない。同じ公開候補でも、新たにデータで裏付けた可読文字が得られれば、その差分と先行貢献を明示して評価する。公開済みモデル確率の単なる再描画は発見件数に含めない。XYだけの違いでは新規性を判定しない。[現行公式条件](https://scrollprize.org/prizes#first-letters-prizes)

主担当レビュー（登録前）で、原案の「公開候補と非重複の別領域が必須」という制限を上記へ修正した。公式に禁止される学習領域との重複と、公開済みだが未判読の入力の利用を混同しない。

# PHerc0211 v9二行目右端の固定元CT断面

公式S3のmasked元CT L0を使ったR235。入力はR234が凍結した [候補・対照計画](../20261115-pherc0211-adjacent-context01/candidate-plan.json) と [主担当承認](../20261115-pherc0211-adjacent-context01/lead-plan-final-check.json)。CT本文は [GET取得原票](ct-acquisition.json) と [HTTPログ](ct-http.jsonl) に残した。既存のL0メタデータはZYX、C順、無圧縮uint8、チャンク128³。`ct.zarr/0/z/y/x` はそのチャンク本文で、これだけで完備したZarrストアにはならない。各ボクセルは9.362 µm。候補箱はXYZ半開 `[4096,4096,8320]–[4352,4352,8576]`、既知φ対照は `[3328,3200,8192]–[3712,3456,8576]`。

全14断面の画素原点、配列、2種の図、描画の補助線は [断面索引](sections-result.json) にある。各 `.npy` は `[row,column]`。

- `*-xy.npy` は候補4・既知4の整数Zにおける元のuint8 DN。表示はXが右、Yが下。サイズは候補256×256、対照384×256（幅×高さ）。
- `*-sd.npy` は候補4・既知2の固定斜断面。列 `s=-80..120`、行 `d=-32..32` を1 voxelずつ進め、`Q=origin+s*t+d*n` でXYZを得る。全78,390標本の8近傍が該当箱内にあり、float64 trilinearの値を保存した。幅201×高さ65。
- `*-raw.png` はDN 0–255の無注釈原寸画像。XYはバイト通り、SDは小数DNを四捨五入。`*-window.png` は同じ配列を窓46–169 DNで全図共通変換した原寸画像。シアンの短い二本線に挟まれた点が原点。シアン方向が負の接線、橙が正の接線。印はv9のXYZ格子点と直線接線の幾何を示す。整数レンダリング画素の中心やCTから追跡した紙層を表す印ではない。

R204/R226の限定取得と描画を参照。凍結済みHEADに対してGETのURL・200・長さ・ETagを照合し、SHA256と単一パートETagに一致するMD5を取得時に保存。R204の元軸抽出・PNG保存・trilinear関数を借用し、trilinearの戻り値でのuint8丸めを外した。XY対照のr40/r44のみ、固定斜断面のある対照r42/r46と同じ中心u差分でXYの補助線を付けた。

初回の描画では42出力を出した後、索引の補助線座標に残ったNumPy整数でJSON保存が停止した。初回実行と部分索引を保存し、座標のPython整数化後に既存42出力の値と画素を再計算と全照合した。再取得および断面画像の上書きは行っていない。 [初回実行](render-process-first.json) · [照合と索引保存の実行](render-process.json)

候補の格子点付近には短く追える層状の帯が見える。正の接線方向では近い帯が接触し、固定箱で同じ一枚を選べない。既知φ付近は暗い間隔が帯を縁取り、候補より帯の配置を読みやすい。元の応答は未確定のまま残し、局所CT診断を終了した。確定新文字0、延長採用0。 [担当所見](visual-review.json) · [親の別目視](lead-visual-review.json)

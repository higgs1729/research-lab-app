# Hecateの深さ窓を一層変えた既知対照

2026-11-14 JST。[研究198](../../../../research/198-hecate-crop-before-reverse-control.md)。PHerc0343の固定入力で、研究196の24→9を23→8に変えると、同じ公開Hecate画像とのMAEが68.8%減った。上中央と右下の明部間に、公開像と同様の暗い分離が戻った。左縁の明部の重心、右上の淡い信号、明部の細かな輪郭には差が残る。

## 条件と結果

- 保存済み33層 `input.npy` を `volume[8:24]` で切り出し、公式 `predict(reverse=True)` に未反転のまま渡した。モデル、重み、XY位置、正規化、Hann集約はR196と同じ。変更後の逆順raw SHAは `589f7ba0dd646f2f3b37d41ff6708236a07787344282615420c4891783c4b5af`。全81パッチの実入力座標、raw SHA、正規化SHA、supportをR197の事前値と照合した。 [事前照合](preflight.json) [主担当の事前入力](lead-input-expected.json) [実行原票](patches.jsonl)
- CPU1、4 GiB commit、数値ライブラリ1threadで公式predictを一回実行。最初3枚の入力照合後、残78枚の見通し469.812秒は残枠4,448.041秒以内だった。81枚を765.861秒で完走。CPU時間436.500秒、peak RSS 1,283,772,416 B、最低空きRAM 9,412,988,928 B。 [見通し](first-three.json) [資源実測](resources.json)
- 主担当が全81入力・331,776確率値を検査し、独立Hann再集約と最終PNGの全102,400画素がビット一致した。比較図の3パネルも元画像の196,608画素と照合した。 [独立検算](lead-verified.json) [主担当の目視と画素照合](lead-visual.json)

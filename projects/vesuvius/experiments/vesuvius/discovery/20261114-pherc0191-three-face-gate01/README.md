# PHerc0191の固定三面で、中央配置窓がcanvas外

三面の固定方位との交点は一意だった。ところが2048×1024窓を交点中心に置く固定条件では左端がcanvas外になった。基準w053を含む全候補で発生したため、CTキーの取得前に停止。生のCT断面と紙層対応の判定は得られず、広域推論への通過面は確定しなかった。 [研究票](../../../../research/213-pherc0191-three-face-ct-gate.md) · [承認済み計画](../20261114-unread-multiwinding-lane01/next-plan.json) · [座標原票](coordinate-plan.json)

公式L0 `20250821151635` のボクセル座標で、z11952・固定点 `[4300,4320]` から `[4656,4656]` へ向かうrayを使用。公開XYZ TIFF 9本525,366 Bを固定Git blobに照合し、metaは既存原文を再利用した。双線形セル内でXY横方向のray制約とZを同時に解いた。名目scale `9.362/9.6` の実float32は0.9752083421、Z stepは1.0254219770 voxel。親担当が別のNewton解で三交点・製品換算・丸めを確認し、最大XYZ成分差は1.82×10⁻¹² voxel。親から最初に定数4310との食い違いが指摘されたが、これは凍結前の草稿。承認SHAと凍結定数4320を再確認し、座標計算は再実行しなかった。 [取得原票](mesh-acquisition.json) · [親の独立照合](lead-coordinate-check.json)

R199の既存製品観測器で、各交点の最近接整数画素一つずつを幾何のみ確認した。CTキャッシュにはメタだけを置いた。捕捉した格子原点は製品のfloat32内部中心を含めて一致し、XYZの双線形計算との差は最大0.000884 voxel。照合初回は内部中心を厳密な半節点数で近似し、格子原点の厳しい比較条件で停止した。照合側でfloat32の内部表現を取り込み、保存観測から確認した。 [製品観測](observer-anchors.json) · [製品格子照合](observer-comparison.json)

費用0。XYZ本文受信3.462秒、座標計算0.933秒、製品三観測の子処理計2.878秒。主要工程はCPU1・commit/AS4 GiB、処理の最大RSSは座標計算73,609,216 B。製品観測はネットワーク分離、Dは読取マウント。C空き確認は約21.8 GiB。CT値、新モデル、推論、GPU、外部公開0。 [XYZ実行](mesh-process.json) · [座標実行](coordinates-process.json)

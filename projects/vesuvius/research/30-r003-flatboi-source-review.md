## 座標の流れ

1. [一次] `flatten()` は `rawPoints()` を複製し、`0 < keep < 100` で `stride = max(2, round(1/sqrt(keep/100)))`。 `decimateGrid` の原点は配列の `(0,0)`。粗格子 `(r,c)` は元格子 `(stride*r,stride*c)` を読む。 `meshGrid` は有効四角形に使う頂点を格子行・列で記録する。 [flatboi](https://github.com/ScrollPrize/villa/blob/7ad02f4f6e306b744ef6d2742dfe31fd55713ee5/volume-cartographer/libs/flatboi/flatboi.cpp#L899-L929) [SurfaceMeshing](https://github.com/ScrollPrize/villa/blob/7ad02f4f6e306b744ef6d2742dfe31fd55713ee5/volume-cartographer/core/src/SurfaceMeshing.cpp#L17-L55)
2. [一次] L929 は粗い `(r,c)` から `(c/scale_x,r/scale_y)` を作る。 `original_ic()` が TC を頂点 UV へコピーし、`slim_precompute` に `soft_penalty=0` で渡す。伸びは三角形ごとの 3D/2D 変形を集約するので、独立成分同士の位置関係はこの指標に現れない。 [初期化](https://github.com/ScrollPrize/villa/blob/7ad02f4f6e306b744ef6d2742dfe31fd55713ee5/volume-cartographer/libs/flatboi/flatboi.cpp#L923-L938) [SLIM・伸び指標](https://github.com/ScrollPrize/villa/blob/7ad02f4f6e306b744ef6d2742dfe31fd55713ee5/volume-cartographer/libs/flatboi/flatboi.cpp#L374-L489)
3. [一次] L957–983 で元格子メッシュに UV を lift。`liftGridUVs` は元の行・列を stride で割り、粗格子の三角形内で UV を重心補間する。無効四角形では最寄りの粗頂点を各軸 ±2 の範囲で探す。見つからなければ頂点は無効のまま。その頂点を含む面を外して出力を元のサンプリング密度でラスタライズし、同じ出力セルに複数面が来れば最初の面を採る。[lift 呼び出し](https://github.com/ScrollPrize/villa/blob/7ad02f4f6e306b744ef6d2742dfe31fd55713ee5/volume-cartographer/libs/flatboi/flatboi.cpp#L955-L983) [補間](https://github.com/ScrollPrize/villa/blob/7ad02f4f6e306b744ef6d2742dfe31fd55713ee5/volume-cartographer/core/src/SurfaceMeshing.cpp#L59-L104) [ラスタライズ](https://github.com/ScrollPrize/villa/blob/7ad02f4f6e306b744ef6d2742dfe31fd55713ee5/volume-cartographer/core/src/SurfaceMeshing.cpp#L480-L500)

## CPU ビルドとテスト

- [一次] 上流 CI の `flatboi-compile` が小さい構成。Ubuntu 26.04 の固定 builder、`volume-cartographer`・`vc_reader`・`vc_object_store` の sparse checkout、`install_build_deps.sh minimal-build`、Ninja / clang・clang++・flang / QuickBuild O0。設定は `VC_TESTING=OFF VC_BUILD_APPS=OFF VC_BUILD_FLATBOI=ON FLATBOI_BUILD_SLIM_TESTS=ON`、ターゲットは `flatboi check_slim_assembly`。CPU を明示する場合は `VC_READER_ENABLE_CUDA=OFF`。最上位は CMake 3.28 と C++23。 [CI](https://github.com/ScrollPrize/villa/blob/7ad02f4f6e306b744ef6d2742dfe31fd55713ee5/.github/workflows/vc3d-ci.yml#L403-L458) [CMake](https://github.com/ScrollPrize/villa/blob/7ad02f4f6e306b744ef6d2742dfe31fd55713ee5/volume-cartographer/CMakeLists.txt) [公式依存スクリプト](https://github.com/ScrollPrize/villa/blob/7ad02f4f6e306b744ef6d2742dfe31fd55713ee5/volume-cartographer/scripts/install_build_deps.sh)
- [一次] `flatboi` のリンクは libigl（`ae8f959…` に上流差分を適用）、PaStiX v6.4.0 / SPM、OpenMP、OpenCV、`vc_core`、`vc_inpaint`。Ceres、Eigen3、nlohmann_json、pkg-config は構成時に必須。兄弟プロジェクトから SQLite3、OpenSSL Crypto、curl、zlib/zstd/lz4/blosc、TIFF/PNG/JPEG、vc-delta3d（`4533974…`）も入る。公式 installer は PaStiX 用に BLAS/LAPACK/LAPACKE、Scotch / ScotchMetis、hwloc、Fortran コンパイラ、Python3 を用意する。Qt と Boost program_options は apps/tests を切れば VC 本体の構成から外れる。さらに `VC_OBJECT_STORE_BUILD_SERVER=OFF` で object-store の Boost 要件を外せる。パッケージを削った構成は未検証。 [flatboi CMake](https://github.com/ScrollPrize/villa/blob/7ad02f4f6e306b744ef6d2742dfe31fd55713ee5/volume-cartographer/libs/flatboi/CMakeLists.txt) [VC CMake](https://github.com/ScrollPrize/villa/blob/7ad02f4f6e306b744ef6d2742dfe31fd55713ee5/volume-cartographer/CMakeLists.txt#L472-L647) [vc_reader native](https://github.com/ScrollPrize/villa/blob/7ad02f4f6e306b744ef6d2742dfe31fd55713ee5/vc_reader/cmake/NativeReader.cmake#L1-L27) [vc_object_store CMake](https://github.com/ScrollPrize/villa/blob/7ad02f4f6e306b744ef6d2742dfe31fd55713ee5/vc_object_store/CMakeLists.txt#L11-L41)
- [一次] `check_slim_assembly` は合成入力で行列・RHS・キャッシュ・非有限値などを検査。`VC_TESTING=ON` なら CTest にも登録される。`test_surface_meshing` は stride サンプリング、無効な外周のある格子の UV lift を検査。`test_tool_store_modes` は store/tifxyz の同値性と `--keep=50` の出力が非空であることを検査。これらに #2500 の成分間重なりを判定するテストは見当たらない。 [assembly](https://github.com/ScrollPrize/villa/blob/7ad02f4f6e306b744ef6d2742dfe31fd55713ee5/volume-cartographer/libs/flatboi/tests/README.md) [meshing](https://github.com/ScrollPrize/villa/blob/7ad02f4f6e306b744ef6d2742dfe31fd55713ee5/volume-cartographer/core/test/test_surface_meshing.cpp#L45-L110) [CLI](https://github.com/ScrollPrize/villa/blob/7ad02f4f6e306b744ef6d2742dfe31fd55713ee5/volume-cartographer/core/test/test_tool_store_modes.cpp#L350-L392)

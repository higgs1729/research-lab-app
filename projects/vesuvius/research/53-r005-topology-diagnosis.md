# R005：粗細メッシュの接続差と、目標勾配を外した診断

2026-11-12 JST。[候補Cの93反転](49-r005-reconcile-trial.md)を粗細メッシュの接続関係に照合した。62面は複数の粗い島につながる未知領域にあり、31面は一つの粗い島につながる領域にあった。粗い島の分離は調べる価値のある特徴だが、全反転の単独原因ではない。粗い三角形5,870面のうち350面には、その格子領域を埋める細面の欠損があった。これも原因を証明する結果ではない。

固定UVを保って目標辺ベクトルだけをゼロにする比較も行ったが、多数の面が潰れる診断となった。この比較を採用候補にせず、反転数の単純比較から固定点の実現不能性を主張しない。Cを研究用の基準として維持する。

## 粗いメッシュと細かいメッシュは同じ接続ではない

保存済みの第二入力、Cの配置前UV、前回の二つの固定条件変更を使った。新しい入力、native実行、ビルドはない。[診断コードと結果](../experiments/vesuvius/r005/20261112-topology01/analysis01/result.json)

| グラフ | 成分数 |
| --- | ---: |
| 細メッシュ | 9 |
| 実際に粗SLIMで使った粗メッシュ | 22 |
| 異なる細成分をまたぐ粗面を除いた診断グラフ | 26 |
| 格子領域が細面で完全に埋まる粗面だけの診断グラフ | 105 |

粗グラフの成分数は全3,954粗点を含む。後二行は辺を除いたときの孤立点も含み、新しく最適化した結果ではない。元の22成分は全て面を持つ。粗面9枚が異なる細成分の点をつないでいた。候補B/Cの勾配延長はこの9面を除くが、その入力となる粗UVを求めたSLIMには含まれていた。

stride 8の粗三角形は、格子座標では64枚の単位細三角形に分割できる。そのうち元の細メッシュに存在する枚数を数えた。完全64枚が5,520粗面、一部欠損が348面、全64枚が欠損するものが2面だった。これは**格子面積の被覆**であり、3D表面積でも、粗三角形の3D形状誤差でもない。完全被覆の面は全て同じ細成分の点を結んでいた。完全被覆だけに絞るとグラフがさらに分かれるため、それをそのまま修正として採用していない。

## 反転がある八つの未知領域

Cの固定点を除いた細辺グラフは346領域に分かれ、その8領域に93反転がある。各領域に隣接する固定点について、floorで選ばれた粗面、または固定した粗サンプルの属する**元の粗グラフ**の成分を数えた。

複数の粗成分につながる五領域に62反転と共通37反転、単一粗成分につながる三領域に31反転と共通14反転がある。前回の最大の反転群は単一粗成分の領域120に属する。したがって、別々の粗い島の配置だけを直せば全て解決するとは言えない。領域90の固定境界に選ばれた粗面は全て完全被覆だったが、そこにも5反転がある。直近の不完全被覆だけでも全反転を説明できない。

独立検算では、全346領域のうち単一粗成分に由来するものが328領域・50,932未知点、複数粗成分が18領域・15,119未知点だった。反転があるのはそれぞれ3領域と5領域。由来不明の`owner = -1`は境界に0点で、粗面から別に補間した非粗点の固定UVもCと全点一致した。複数粗成分の領域で反転が目立つが、これは一つの入力内の対応関係であり、介入によって原因を確定したものではない。

ここで数えたのは隣接する固定点の由来である。離れた場所から同じ粗SLIMを通じて受ける影響や、固定値どうしが向き保存と両立するかまでは測定していない。

## 目標勾配をゼロにした比較は縮退した

Cと同じ183,893固定点、66,051未知点、重複を除いた細辺、格子辺長の逆数を残差へ掛ける重みを使い、目標辺ベクトルだけを0にした。全ての固定値と粗点を厳密に保持し、正規方程式の相対残差は約1.02×10⁻¹⁵だった。[比較の結果](../experiments/vesuvius/r005/20261112-topology01/harmonic01/result.json)

この目的関数は未知領域の辺を短くする。外周の未知点を元の形に留める条件がないため、細い突出部などの面積が潰れ得る。生の浮動小数点計算で負の面積28,191面、面積が厳密に0の面134面、Cの93反転のうち55面が負、前回の共通51反転のうち30面が負となった。ただし、0付近の符号は丸めに敏感であり、これを全て安定した反転と数えて比較するのは不適切である。この診断から、固定値だけで正向きの解が不可能だとは結論しない。目標勾配を単に外す案は採用しない。

独立検算では、Cと診断UVの各面の最長辺長二乗の大きい方を`S`とし、二倍符号面積の絶対値が`閾値×S`以下なら近ゼロとして集計した。

| 閾値 | 負 | 近ゼロ | Cの元93面：負 / 近ゼロ / 正 | 前回共通51面：負 / 近ゼロ / 正 |
| --- | ---: | ---: | ---: | ---: |
| 10⁻¹² | 27,624 | 1,263 | 53 / 2 / 38 | 28 / 2 / 21 |
| 10⁻⁶ | 25,880 | 4,985 | 53 / 2 / 38 | 28 / 2 / 21 |

各座標を1 ULP動かした場合の面積感度でも、元の93面は53 / 2 / 38だった。これらは保存UVの判定尺度であり、疎系の真の解への前進誤差の上界ではない。多数の負面積が相対閾値を超えて残り、別目的への変更が明確に悪化した比較である。近ゼロを区別しても、これだけで元の問題の正向き解の実現可能性は決まらない。

## 検証・資源・次の判断

別担当にgpt-6.1-sol / highを選び、粗面の格子被覆、全グラフと境界の対応、疎系、面積の符号と縮退の尺度を独立確認した。格子被覆は整数重心の半平面判定から全粗面の細面ID集合を照合し、独立したグラフ再構成でも全て一致。診断UVの疎系残差は9.76×10⁻¹⁶、固定値と全ての負符号面IDも一致した。主担当の二つの処理を終えてから検証へ移り、追加実験を重ねていない。[独立検証](54-r005-topology-verification.md)

接続診断は9.24秒・最大RSS358,043,648 bytes、目標勾配を外す比較は18.11秒・375,164,928 bytes。いずれもCPU 1個・数値ライブラリ1スレッド、300秒・RSS 4 GiBの監視内で完了した。壁時計は共有ホスト上の値である。新しい有料計算、入力ダウンロード、ライブラリの導入は0。LLMとローカル電気代は個別計測していない。

独立検算は19.75秒・最大RSS273,555,456 bytesで、同じ資源制限内で完了した。

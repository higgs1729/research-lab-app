対象は既存PHerc0814の二実面、keep100・5反復。保存済み未配置対照と比較し、既存有効格子点の所有元面・XYZ・補間支持/ウェイトを整数移動先で確認、同成分拒否と異成分混合を分離し、露出点の数と元面を示す。新たな全数のネイティブ結果でR149保存計算だけでは未保証だった部分を確かめる。既定offと従来packの回帰も、小さい必要十分な範囲で確認する。試作と観測差分/ビルドを分ける場合は出自・一致を保存する。二面以外や下流CTまで広げない。下流画素の完全一致・文字の読みやすさはこの試作の成功条件にしない。

## 結果

`--pack-components-preserve-grid` を指定した隔離flatboiのネイティブ試作で、固定二面の元のサンプリング格子を保ったまま異成分を分離できた。既存 `UvGridRasterizer` で元のUVを1/256セルに丸めてから、成分ごとのX整数セル移動を加え、元の走査範囲も同じセル数だけ移した。元面順、既存の整数辺判定と重心計算を用いる。元写像と出力幅を分け、配置幅が固定小数点またはセル数の上限に達した場合はエラーにする設計とした。今回の二面は上限内に収まった。

| ネイティブ結果 | 一面目 | 二面目 |
| --- | ---: | ---: |
| 格子の高さ×幅（未配置 → 試作） | 172×553 → 172×683 | 252×2637 → 252×3033 |
| 所有元面とXYZの全ビットを整数移動先で保持した元所有点 | 40,944 | 254,263 |
| 実C++の3ウェイトと元格子からの再構成がビット一致した全所有点 | 41,133 | 254,662 |
| 異成分の拒否件数（未配置 → 試作） | 189 → 0 | 399 → 0 |
| 同成分の拒否件数（未配置 → 試作） | 1 → 1 | 358 → 358 |
| 試作の異成分隣接辺・四隅有効な混合四角形 | 0・0 | 0・0 |
| 新たに露出した独立所有点 | 189 | 399 |

露出点の移動先、元格子、元面IDと成分IDを `verify-all.json` に全件保存した。保存済み未配置で同一座標を主張した全元面と拒否元面を移し、試作の所有と残存拒否を照合した。既存未配置原票のウェイトは、元UV・元面・既存固定小数点計算から再構成した。観測版が実際に使用した3ウェイトと一致し、そのウェイトと元の頂点XYZから再計算した全点も出力TIFFのfloat32値とビット一致した。二面目の研究145固定368候補で所有点0の元面は184のまま、0と正の間を移った候補も0。名目scaleは両面の対照・試作ともに同じ。

既定動作と従来 `--pack-components` は一面目で、それぞれ保存原票のXYZ TIFF三枚、観測JSON二件、SLIM energy一件のSHA-256と名目scaleが一致した。一面目の新モードでは観測なし試作と観測版のXYZ TIFF三枚もSHA-256一致。両配置フラグの同時指定を拒否することを確認した。TIFXYZ入口では配置済みUVのOBJを作らず、観測JSONは元UVを `source_grid_uvs` として保存した。

固定ソース・既存CMake設定と既存依存を借り、変更ヘッダーを使うflatboiとSurfaceMeshingの2翻訳単位をC:でビルドした。`UvGridRasterizer` のインスタンスレイアウトが変わるため、今回のELFは両翻訳単位と全ラスター実定義を同梱し、その他の依存に旧共有ライブラリを使った。共有ライブラリを単独で差し替える場合は、同クラスを使う旧バイナリとのABIを確認する必要がある。keep<100、store入口、一成分、小成分、非有限値、幅上限での動作は今回の実証範囲外。元の配置点を使う下流CT・再サンプリング画素・判読性の評価も行っていない。

1CPU、数値1スレッド、AS 4 GiB、core 0、WSLネットワーク分離で実行した。コンパイル・リンクの実測累計77.694秒、コメント修正の前処理照合24.395秒、ネイティブ試験202.518秒（run01のhelpを含む）。ビルドの最大RSSは1,571,307,520バイト、ネイティブの最大RSSは1,029,238,784バイト。ネットワーク取得0バイト、追加クラウド支出0円。失敗・修正履歴、原票・再現手順、登録候補を[実験README](../experiments/vesuvius/r005/20261113-grid-preserving-native01/README.md)に収録した。試作の採否は主担当の独立検証後に決める。

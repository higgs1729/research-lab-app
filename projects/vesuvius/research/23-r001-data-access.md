## 転写の契約と比較

公式 `tifxyz_label_transfer` は配列の順序を YX、各節点に保存する値を XYZ のスキャンボクセル単位とする。メタデータ `scale` は XY の格子密度で、ライブラリ上は YX。w00公開メッシュは両軸0.05、ラベルの縦横は格子数の20倍。既定の画素中心は `g=(pixel+0.5)*stored_size/rendered_size`。クロップを使う場合も、グローバル画素・格子原点とこの位相を保持する。既存 CLI の `single` は同一面間の転写、`pipeline` は二段階。別スキャンでは `--affine-direction forward` なら `p_target=M*p_source`。ラベルキャンバスの測定済み補正は `--label-canvas-offset DY DX` でラベル `(i,j)` をソースキャンバス `(i+DY,j+DX)` へ対応付ける。 `prepare_canvas_offset_evidence` / `estimate_canvas_offset_evidence` は CT 画像を使った原点検査、`self_render_tifxyz` は独立の CT 確認。 [core.py](https://github.com/ScrollPrize/villa/blob/c86cbd14bb34e0124684d3d97b03b310c947819a/vesuvius/src/vesuvius/tifxyz_label_transfer/core.py) · [CLI仕様](https://github.com/ScrollPrize/villa/blob/c86cbd14bb34e0124684d3d97b03b310c947819a/vesuvius/src/vesuvius/tifxyz_label_transfer/docs/reference.md)

狭い領域で、gen-19 対象画素の 3D位置から w00 の最近傍三角形へ投影し、重心座標で w00 格子位置、次いでラベル画素を求めてカテゴリを最近傍サンプルする。逆方向で紙面候補を見つけ、近接する別の巻きを距離・法線・往復照合で落とす。公式 CLI の `valid==255` 相当の幾何一致と supervision の共通部分で、同じ画素群を用いて `(0,0)`、`(+19,+19)`、`(+20,+20)` の予測位置を比較する。gen-19 Hecate のレベル0は Zarr v3、4,096²シャード内に512²の Zstd チャンクがあり、シャード末尾の索引は1,028 bytes。候補の画素座標が分かってから索引と内部チャンクだけ Range で読む。ローカル Python に numpy/scipy/tifffile は存在し、zarr/numcodecs/blosc2 の import は見つからなかった。 [転写の幾何とvalidity](https://github.com/ScrollPrize/villa/blob/c86cbd14bb34e0124684d3d97b03b310c947819a/vesuvius/src/vesuvius/tifxyz_label_transfer/docs/theory.md) · [Hecateレベル0仕様](https://vesuvius-challenge-open-data.s3.us-east-1.amazonaws.com/PHercParis4/segments/20260926044226-spiral-output-generation-19/ink-detection/PHercParis4-20260926044226-2.4um-0.22m-78keV-volume-20260411134726-20260915161132-hecate-9.6um-L2-l64-accmax4-reverse.zarr/0/zarr.json)

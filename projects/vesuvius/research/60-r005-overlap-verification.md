# R005の固定面と新生したUV重なりを独立検証

2026-11-12 JST。PHerc0814二面目の候補C・Dについて、描画拒否の分類、配置前の固定幾何、特定の三角形ペアの連続UV重なりを保存データから確認した。前回の凍結証拠197ファイル、入力TIFFとメタデータ、二つの診断のソース・保存スナップショット・参照配列のハッシュを照合した。[C/Dの独立検証](58-r005-slim-patch-verification.md)

## 描画拒否と固定点

有効UVで絞った描画面番号を元の入力面番号に戻した。C・Dとも全UVが有効で、描画面番号と元面番号は一致した。全拒否イベントで記録された先着面が画素の所有面と一致し、採用面と拒否面は同じ細格子成分に属していた。固定点は候補Cの配置前の固定マスクに基づく。

各イベントの画素を描画範囲と格子の寸法から連続UVへ有理数で戻し、保存三角形の有向面積比から重心係数を再計算した。係数6個がすべて正だったイベント数は、主計測が `10⁻⁸` より大きい係数を用いて分類した個数と一致した。

| 計測 | C | D |
| --- | ---: | ---: |
| 描画拒否イベント | 416 | 638 |
| 両面の厳密な内部に入る画素 | 414 | 635 |
| そのうち両面が頂点を共有しない | 405 | 635 |
| 片方の面だけ全3頂点が固定 | 48 | 94 |
| 両面とも全3頂点が固定 | 0 | 0 |

この表は保存された描画画素のイベントを数える。同じ面ペアが複数画素で拒否される場合や、画素間にある重なりは別であり、全三角形ペアの重複数を表さない。[主計測の分類](../experiments/vesuvius/r005/20261112-overlap01/analysis01/result.json) [有理数による独立分類](../experiments/vesuvius/r005/20261112-overlap-verification01/check01/result.json)

## 配置前の固定幾何の全域検査

入力TIFFから細格子を再構成し、固定183,893点を用いて全3頂点が固定の348,981面、両端が固定の一意な532,703辺を抽出した。配置前ではこれらの頂点UVがC・Dで一致する。9つの細格子成分ごとに、Shapely 2.1.2／GEOS 3.13.1のSTRtreeで外接矩形が交わる候補を列挙した。ここまでは主計測と同じ空間索引を利用した。

候補の交差判定は独立の式で行った。保存UVを成分・座標軸ごとの2のべき乗で整数へ厳密に変換し、積と差の桁あふれを検査した。三角形では双方の各辺を分離軸として内部の重なりを判定し、線分では両端が相手の線分の両側へ厳密に分かれる条件を調べた。面2,290,925組、辺2,929,421組を判定し、面内部の重なりは0組、線分の真の交差は0組。GEOSの関係述語を用いた主計測と一致した。[主計測の固定幾何結果](../experiments/vesuvius/r005/20261112-overlap01/geometry01/result.json) [独立の固定面・固定辺番号](../experiments/vesuvius/r005/20261112-overlap-verification01/check01/fixed_geometry_ids.npz)

整数判定が厳密なのは、列挙した候補と保存座標に対する面内部・真の交差の判定。辺の共線重複、端点だけの接触、固定点だけの一致、異なる成分間の比較、未知点を含む面はこの全域検査の対象外。配置前の固定部分についての陰性結果から、固定値と両立する全メッシュの単射写像の存在は決まらない。

## 面159157と面188235の厳密な例

両面は細格子成分1にあり、共有頂点は0。面159157は全3点が固定で、面188235は全3点が未知領域129。配置済みCではX方向に `2641/128 = 20.6328125` UV単位の厳密な間隔があり、両面の閉じた三角形は離れている。

配置済みDの描画画素 `(529,121)` に対応する連続UVを、保存トレースから独立に `(2746344233/259584, 1207168721/499712)` と計算した。元の保存UVから面積比で求めた両面の有理重心係数は全て正で、各面で和は厳密に1。最小係数は約0.0157070で、共通点は双方の内部にある。この共通UV点を二面でそれぞれ補間したXYZの距離は約583.81 CTボクセルだった。主計測がGEOSの交差領域から選んだ点とは別の証拠点を使った。[配置後の分数と点の対応](../experiments/vesuvius/r005/20261112-overlap-verification01/check01/result.json)

同じペアを配置前でも照合した。成分1の配置の平行移動はC・Dで一致し、面159157の配置前UVも一致した。Cの配置前のX方向には約20.63291438 UV単位の間隔がある。Dでは上の共通点から平行移動を差し引いた点が、配置前の両面の内部にも入り、最小有理重心係数は約0.01569429だった。このペアの衝突はCからDへの変更で新しく生じ、float32の配置変換と描画格子の影響を受ける前から存在した。ほかの拒否イベントの新旧や、全重なりの増減はこの一例から判定しない。[配置前の厳密な分数](../experiments/vesuvius/r005/20261112-overlap-verification01/check02/result.json)

独立検証は既存runnerを使いCPU 1個・1スレッド、各300秒・RSS 4 GiB監視で逐次実行した。全域検査と画素分類は22.72秒・最大観測RSS 402,866,176バイト、配置前の照合は2.36秒・273,494,016バイト。入力の追加取得、依存導入、ビルド、求解、描画の再実行、有料計算は0。[全域検証コード](../experiments/vesuvius/r005/20261112-overlap-verification01/verify_overlap.py) [配置前照合コード](../experiments/vesuvius/r005/20261112-overlap-verification01/verify_case_prepack.py) [全域検証の実行記録](../experiments/vesuvius/r005/20261112-overlap-verification01/check01-execution/state.json) [配置前照合の実行記録](../experiments/vesuvius/r005/20261112-overlap-verification01/check02-execution/state.json)

# R001の追加2 ROIの独立検証

2026-11-11 JST。w00 の事前選定タイル (26, 67) と (27, 51) で、gen-19 Hecate の予測を両軸に +19 px または +20 px ずらして読むと、シフト0より ROC AUC が上がった。+19 と +20 の順位はタイルで逆転した。[事前計画](../experiments/vesuvius/r001/20261111-multiroi-plan.json)・[先行ROIの独立検証](24-r001-roi-verification.md)

## 保存値と全探索

キャッシュの HTTP 本文は保存した SHA-256 と照合した。TIFF の XYZ クロップ、Zarr の ink・supervision タイル全画素、3シフトの予測全16,384点をバイト列から復元し、保存値と一致した。保存投影から valid を再構成すると完全一致し、各ROIの3シフトを同じ点で比較した AUC は元の報告値と完全一致した。

| タイル YX | valid（陽性 / 陰性） | シフト0 | 両軸 +19 px | 両軸 +20 px |
|---|---:|---:|---:|---:|
| (26, 67) | 8,100（4,652 / 3,448） | 0.601115 | 0.898003 | 0.909535 |
| (27, 51) | 9,601（2,420 / 7,181） | 0.804867 | 0.972185 | 0.967019 |

倍精度の独立投影で16,384点すべてについて順方向858三角形・逆方向1,922三角形を各クロップ内で全探索した。両ROIとも勝った三角形の重心距離順位は最大5位で、元実装の24候補制限に収まった。(26, 67) は valid に2点が加わり1点が外れ、8,101点で AUC 0.601131 / 0.897934 / 0.909480。(27, 51) の valid は同じ9,601点で、AUC は 0.804901 / 0.972185 / 0.967021 だった。

保存投影でターゲットの共通位相 −0.5 / 0 / +0.5 px と距離上限 0.5 / 1 / 2 / 3 / 4 L2 ボクセルを組み合わせた15条件でも、両シフトともシフト0を上回った。(26, 67) の +19 対0の差は +0.2241〜+0.2997、(27, 51) では +0.1242〜+0.2156。(26, 67) では全15条件で +20 が +19 を上回り、(27, 51) では条件によって順位が逆転した。

## 中心点のクロップ外候補

ROI中心を、キャッシュにあるターゲット TIFF の連続26行・全56,913列で三角形へ投影した。保存クロップに含まれる三角形と、それ以外の三角形の最近傍を距離で比較した。

| タイル YX | 探索行（終端を除く） | クロップ内の距離 | クロップ外の距離 | 投影先同士の格子距離 |
|---|---|---:|---:|---:|
| (26, 67) | [198, 224) | 2.537 | 17.229 | 120.74 |
| (27, 51) | [204, 230) | 0.869 | 15.743 | 125.01 |

距離の単位は L2 ボクセル。両ROIの中心点でクロップ内の候補が近かった。(26, 67) の中心点自体は、比較に使った距離 <2 の条件を外れる。中心点以外とキャッシュ行の外側ではクロップ外候補を検査していない。AUCは幾何候補の選択に使っていない。

追加2 ROIは同じ w00 セグメントにある。別セグメント、独立注釈ラベル、予測の生成・表示で生じる位置ずれの原因は、この検証の範囲外。

## 再実行

CPUで全点の再計算は約14秒と16秒、ラベルと中心点の照合は約3秒と2秒。追加通信0バイト、有料計算の新規調達0 USD。`$roiRun` を `03` に変えると2件目を再実行できる。出力には新しいパスを指定する。

```powershell
$r001 = 'experiments/vesuvius/r001'
$roiRun = '02'
$auditOut = "$r001/recheck-$roiRun"
python -B "$r001/20261111-verify02/verify_roi.py" --probe "$r001/20261111-probe$roiRun" --compare "$r001/20261111-compare$roiRun" --out $auditOut
python -B "$r001/20261111-verify02/verify_cached_center.py" --probe "$r001/20261111-probe$roiRun" --out "$auditOut/cached-center.json"
```

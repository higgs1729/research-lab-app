# R005の追加成果：元の採取格子を保つ成分配置

2026-11-13。主担当は研究149–151を、既存R005を深める追加の技術的証拠として採用した。11月の応募候補は三件のまま。今回の差分と根拠はローカルに保存し、公開済みの三件・凍結パッケージは変更していない。

従来の任意配置は、全体の幅と格子の位置も変える。追加の `--pack-components-preserve-grid` は、元の格子を確定してから各成分を整数セルだけX方向へ移す。そのため、元の採取点を保ちつつ、別成分に隠れていた点を取り戻せる。

| 固定PHerc0814入力 | 第一面 | 第二面 |
|---|---:|---:|
| 元の所有面とXYZ全ビットを保持した点 | 40,944 | 254,263 |
| 配置後の全有効点 | 41,133 | 254,662 |
| 回復した独立した点 | 189 | 399 |
| 異成分の拒否 | 189→0 | 399→0 |
| 同成分の拒否 | 1→1 | 358→358 |

二面はkeep100・5反復のTIFXYZ入口で確認した。実装担当と別の検証担当が元と移動後の全三角形を独立に列挙し、全有効点の重心ウェイトもビット一致した。観測機能を持たない製品版も両面でXYZ TIFF三枚と名目scaleが観測版に一致。第一面の既定・従来packは保存済み各6ファイルに一致した。[成立性149](../../../../research/149-r005-packing-grid-phase-feasibility.md) · [ネイティブ試作150](../../../../research/150-r005-grid-preserving-native-prototype.md) · [独立検証151](../../../../research/151-r005-grid-preserving-verification.md)

再利用の入口は[差分と実行手順](../../../../experiments/vesuvius/r005/20261113-grid-preserving-native01/README.md)。公開済みR005差分に試作差分を重ねる。元のソース・依存を残し、出力先を分けて再現する。新コードは既存のラスターを拡張しており、別の製品ラスターを作ったものではない。

採用した主張はTIFXYZの採取点と補間割合の保持まで。CT描画後の画素完全一致や文字判読の改善は未検証。下流の浮動小数点座標や近傍の支持は別に確認する。keep<100・store入口・非有限/一成分/小成分・極端な上限入力は未検証。UvGridRasterizerのクラスサイズが変わるため、試験は同じ新ヘッダーで二つの翻訳単位を作り直した隔離ELFに限る。共有ライブラリだけを旧バイナリへ差し替える配布物としては扱わない。

研究150/151の追加クラウド支出・データ取得は0。既存のコード・データのライセンスはそのまま。公開や上流への送信はこの採用に含めない。

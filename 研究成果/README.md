# 研究成果(抜粋)

このアプリの元になった研究体制で、AI が実際に進めた研究(Vesuvius Challenge:炭化した古代の巻物を CT から読む懸賞金問題)の記録の抜粋です。元の記録は約 250 本あり、ここには全体像が分かるものだけを入れました。文中のリンクは元のフォルダ構成を指しているため、ここでは開けないものがあります。

| ファイル | 中身 |
|---|---|
| 01_研究の経過と方針.md | 方針、要件 R1〜R6、研究の経過(R001〜R005 の履歴) |
| 02_研究体制の基本設計.md | 主担当・日次監査・ハートビートの設計(アプリの元の設計) |
| 03_投入配分の判断_20261118.md | 次にどの研究へ資源を回すかの判断の例 |
| 04_11月応募の成果一覧.md | 11 月の Progress Prizes へ出す成果の一覧と現在の状態 |
| 05_応募原稿.md | 応募文の下書き |
| 研究ノート/ | 研究 1 件ごとの記録と、別担当による独立検証の例 |

## アプリで開ける記録との関係

ここにあるのは読み物としての抜粋です。元の研究体制が残した研究記録そのもの(359 件、根拠ファイルつき)は `projects/vesuvius/` に入っていて、`python app.py --research` で画面から検索・照合できます。根拠ファイルは容量の都合で一部だけを入れています(詳しくは `docs/使い方.md`)。
